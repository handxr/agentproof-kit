## Rules

### conventional-commits

Write commit subjects as `type(scope): summary` with type one of feat, fix, docs, refactor, test, chore.
Keep the subject under 72 characters. Explain why in the body.

### react

Applies to `src/components/**/*.tsx`.

One component per file. Named exports only. Keep effects out of render paths.

### typescript-strict

Applies to `**/*.ts`, `**/*.tsx`.

Never use `any`. Parse external data at the boundary and pass typed values inward.
Prefer discriminated unions over optional fields that depend on each other.
